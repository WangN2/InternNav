# 第 5 章 · 环境封装与评测链路

## 本章目标

学完本章后，你能：
1. 对比 Habitat、InternUtopia、RealWorld 三种环境的动作空间与适用场景。
2. 说明 `vln_distributed`、`habitat_vln`、`habitat_evaluator` 三种评测器的区别。
3. 跑通一次 Habitat 或 InternUtopia 评测，并理解配置中每个关键字段。
4. 理解 client-server 评测的启动方式与最佳实践。

---

## 讲解

### 5.1 HabitatEnv

- 平台：Meta Habitat 仿真器
- 动作空间：**离散**（stop / forward / turn_left / turn_right / look_up / look_down）
- 文件：`internnav/env/habitat_env.py`
- 适用：VLN-CE、System 2 评测

### 5.2 InternutopiaEnv

- 平台：InternUtopia / Isaac Sim 物理仿真
- 动作空间：**连续控制器指令**（`move_by_discrete`、`vln_dp_move_by_speed`、`move_by_flash` 等）
- 文件：`internnav/env/internutopia_env.py`
- 适用：VLN-PE、Dual-System VLN 评测

### 5.3 RealWorldEnv

- 平台：真实 ROS1 机器人 + RealSense
- 动作空间：**离散整数** `[0, 3]`（stand still / forward / left / right）
- 文件：`internnav/env/realworld_agilex_env.py`
- 适用：真实世界 demo

### 5.4 评测器

| 评测器 | 注册 key | 环境 | 用途 |
|--------|---------|------|------|
| VLNDistributedEvaluator | `vln_distributed` | InternUtopia | VLN-PE 分布式评测 |
| HabitatVLNEvaluator | `habitat_vln` | Habitat | InternVLA-N1 Habitat 评测 |
| HabitatDefaultEvaluator | `habitat_evaluator` | Habitat | 通用 Habitat 评测 |
| HabitatDialogEvaluator | `habitat_dialog` | Habitat-VLLN | 多轮对话导航 |

### 5.5 常见评测命令

```bash
# InternUtopia VLN-PE
python scripts/eval/eval.py --config scripts/eval/configs/h1_internvla_n1_async_cfg.py

# Habitat dual-system
python scripts/eval/eval.py --config scripts/eval/configs/habitat_dual_system_cfg.py

# 带 server 的评测
python scripts/eval/start_server.py --config scripts/eval/configs/h1_cma_cfg.py
python scripts/eval/eval.py --config scripts/eval/configs/h1_cma_cfg.py
```

## 关键代码走读

### `internnav/env/internutopia_env.py`

`reset()` 与 `step(action)` 如何包装 InternUtopia 向量环境。

### `internnav/evaluator/vln_distributed_evaluator.py`

状态机 `NORMAL / WARM_UP / NOT_RESET / TERMINATED / STOP` 与动作转换逻辑。

### `internnav/configs/evaluator/vln_default_config.py`

`get_config()` 如何根据 `robot_name`、`scene_type` 填充默认配置。

### `scripts/eval/bash/eval_vln_distributed.sh`

三种运行模式：`habitat`、`internutopia`、`internutopia_vec_env`。

---

## 小结

- Habitat 适合离散 VLN，InternUtopia 适合连续物理环境，RealWorld 用于真实部署。
- `vln_distributed` 是 InternUtopia 的主力评测器，内部有复杂的状态机。
- 评测配置通常由 `vln_default_config.py` 填充默认值，用户只需覆盖关键字段。
