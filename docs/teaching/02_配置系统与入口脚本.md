# 第 2 章 · 配置系统与入口脚本

## 本章目标

学完本章后，你能：
1. 说明 InternNav 使用哪种配置系统，以及配置文件的两种形式。
2. 独立修改一个训练配置和一个评测配置。
3. 跑通 `train.py`、`eval.py`、`start_server.py` 三个入口，并解释它们的工作流程。
4. 理解 client-server 评测架构的设计目的与安全注意事项。

## 讲解

### 2.1 Pydantic 配置系统

InternNav 的配置主要是 **Pydantic `BaseModel`**，大多设置了 `extra='allow'` 以便向前兼容。核心配置类包括：

- `AgentCfg`：`internnav/configs/agent/__init__.py`
- `EvalCfg` / `EnvCfg` / `TaskCfg`：`internnav/configs/evaluator/__init__.py`
- 模型配置：`internnav/configs/model/{cma,rdp,seq2seq,navdp,internvla_n1}.py`
- 训练实验配置：`internnav/configs/trainer/exp.py`

### 2.2 训练入口

`scripts/train/base_train/train.py` 使用 `tyro.cli(TrainCfg)` 解析参数：

```bash
python scripts/train/base_train/train.py --name my_rdp --model rdp
```

流程：
1. 解析 `--name` 和 `--model`。
2. 根据 `model_name` 加载 `ExpCfg`（来自 `scripts/train/base_train/configs/`）。
3. 实例化对应 `Trainer`（如 `RDPTrainer`）。
4. 调用 `trainer.train()`。

### 2.3 评测入口

`scripts/eval/eval.py` 加载一个 Python 配置文件，该文件暴露 `eval_cfg`：

```bash
python scripts/eval/eval.py --config scripts/eval/configs/h1_rdp_cfg.py
```

当 `eval_type == 'vln_distributed'` 时，会用 `internnav/configs/evaluator/vln_default_config.py` 填充默认配置。

### 2.4 服务入口

`scripts/eval/start_server.py` 启动 FastAPI AgentServer：

```bash
python scripts/eval/start_server.py --config scripts/eval/configs/h1_rdp_cfg.py
```

路由包括 `/agent/init`、`/agent/{name}/step`、`/agent/{name}/reset`。观测通过 `pickle + base64` 在 HTTP 上传递。

---

## 小结

- 训练入口用 tyro 解析，评测入口直接加载 Python 配置对象。
- VLN-PE 评测依赖默认配置填充器来减少重复配置。
- AgentServer 解耦推理与 rollout，但 pickle 传输带来安全风险，不能暴露到公网。
