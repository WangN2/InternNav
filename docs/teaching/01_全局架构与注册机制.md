## 讲解

### 1.1 InternNav 是什么

InternNav 是一个面向具身导航的 PyTorch 工具箱，同时支持：
- **VLN-CE**：Habitat 中的离散视觉语言导航。
- **VLN-PE**：InternUtopia / Isaac Sim 中的连续物理环境导航。
- **VN**：给定目标点 / 图片 / 轨迹的视觉导航。
- **Dual-System VLN**：System 2 高层规划 + System 1 低层控制。

### 1.2 为什么用注册机制

为了让训练、评测、部署能灵活组合不同模型与环境，而不需要为每种组合写死代码。注册机制让新增一种 Agent/Env/Evaluator/Policy 只需「实现 + 装饰器」，框架自动发现。

### 1.3 四大抽象

| 抽象 | 职责 | 关键文件 |
|------|------|---------|
| Agent | 根据观测决定动作 | `internnav/agent/base.py` |
| Env | 封装仿真器/真实机器人，提供观测 | `internnav/env/base.py` |
| Evaluator | 编排「环境 → Agent → 环境」循环，计算指标 | `internnav/evaluator/base.py` |
| Policy | 模型前向计算，输出动作/轨迹 | `internnav/model/__init__.py` |

### 1.4 数据流示例

```text
scripts/eval/eval.py
    │
    ▼
EvalCfg { agent, env, task, eval_type }
    │
    ▼
Evaluator.init(cfg)
    ├─ Env.init(env_cfg, task_cfg)  → habitat / internutopia / realworld
    └─ AgentClient(agent_cfg) 或 Agent.init(agent_cfg)
            │
            ▼
    Agent.step(obs) → Policy.forward(obs) → action
            │
            ▼
    Env.step(action) → next_obs, reward, done, info
```

## 关键代码走读

### `internnav/agent/base.py:6-37`

```python
class Agent:
    agents = {}

    @classmethod
    def register(cls, agent_type: str):
        def decorator(agent_cls):
            cls.agents[agent_type] = agent_cls
            return agent_cls
        return decorator

    @classmethod
    def init(cls, config: AgentCfg):
        return cls.agents[config.model_name](config)

    def step(self, obs, **kwargs):
        raise NotImplementedError
```

### `internnav/env/base.py:6-54`

与 Agent 类似的类级注册表，通过 `@Env.register("habitat")` 等方式注册。

### `internnav/evaluator/base.py:6-39`

Evaluator 基类持有 `evaluators` 注册表，并在 `__init__` 中创建 `Env` 与 `AgentClient`。

### `internnav/model/__init__.py`

通过字符串名返回策略类与配置类的工厂函数：

```python
def get_policy(name): ...
def get_config(name): ...
```

## 小结

- InternNav 用四层注册机制解耦模型、环境、评测与策略。
- 新增组件只需继承基类 + 装饰器注册，即可被入口脚本使用。
- 理解 `Agent.init` / `Env.init` / `Evaluator.init` / `get_policy` 是阅读后续章节的基础。
